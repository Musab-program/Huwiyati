# خارطة طريق مشروع هويتي (Huwiyati Backend Roadmap)

يقدم هذا المستند الفهرس العام والخارطة الشاملة لمشروع "هويتي" (نظام إدارة الهوية الرقمية والخدمات المدنية).

---

## 📌 الفهرس العام للمراحل (Phases Overview)

| رقم المرحلة | اسم المرحلة | الحالة | الوصف المختصر |
| :--- | :--- | :---: | :--- |
| **المرحلة الأولى** | إعداد البنية التحتية والمشروع | ✅ مكتملة | إنشاء حل `.NET 9` بنمط `Clean Architecture` والمشاريع الأربعة (`Domain`, `Application`, `Infrastructure`, `API`). |
| **المرحلة الثانية** | نمذجة السجل المدني والهوية | ✅ مكتملة | إنشاء كيانات `Person` و `ApplicationUser` وإعداد `EF Core` مع `SQL Server`. |
| **المرحلة الثالثة** | تسجيل حساب المواطن | ✅ مكتملة | ربط التسجيل برقم الهوية والسجل المدني، وتأكيد الهوية وإسناد دور `Citizen` تفرعياً. |
| **المرحلة الرابعة** | التفعيل عبر الـ OTP تسجيل الدخول و JWT | ✅ مكتملة | إنشاء الـ `VerificationCode` وتفعيله عبر `VerifyOTP` وتوليد `JWT Token`. |
| **المرحلة الخامسة** | استعادة كلمة المرور | ✅ مكتملة | دعم دورة `Forgot Password` بالكامل (طلب الكود، الفحص، وتغيير كلمة المرور). |
| **المرحلة السادسة** | إدارة الأجهزة الموثوقة (Trusted Devices) | ✅ مكتملة | تقييد الدخول بـ `DeviceIdentifier` إجباري، والتحقق من الأجهزة الجديدة عبر `VerifyDevice`. |
| **المرحلة السابعة** | الصلاحيات والأدوار (Authorization & Roles) | ✅ مكتملة | تهيئة الأدوار `AppRoles` زرعها تلقائياً بـ `DbInitializer` وحماية الـ `Endpoints` بـ `[Authorize(Roles = "...")]`. |
| **المرحلة الثامنة** | الخدمات المدنية وتصاريح المعاملات | ⏳ قادمة | طلبات بطاقات الهوية، جوازات السفر، والتصاريح الذكية. |
| **المرحلة التاسعة** | سجل العمليات والتدقيق (Audit Logs) | ⏳ قادمة | تتبع كافة التحركات والتعديلات وحماية البيانات الحساسة. |
| **المرحلة العاشرة** | الإشعارات والربط الخارجي (Notifications & Integrations) | ⏳ قادمة | دعم إشعارات الـ `SMS` و `Email` والربط مع المنصات الحكومية. |
